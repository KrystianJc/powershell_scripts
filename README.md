# powershell_scripts

Small PowerShell scripts for everyday tasks.

## steam_wall_of_shame

Lists unplayed games from your Steam library with current and regular prices.
Requires a Steam Web API key. See `config.example.json`.

## steam_library_compare

Compares two Steam libraries and lists the games both players own, with each
player's playtime side by side. Interactive menu. Requires a Steam Web API key.
See `config.example.json`.
